Privacy Policy

SentimenTrader for TradingView — Last updated: September 30, 2026

Overview

SentimenTrader for TradingView is a browser extension that displays SentimenTrader sentiment indicators on TradingView charts. This privacy policy describes how the extension handles your data.

Data Collection

The extension does not collect any data.
  • No analytics or telemetry
  • No user behavior tracking
  • No data sent to any server other than sentimentrader.com (your own API requests)

Data Storage

Login Credentials

  • Your SentimenTrader username and password are stored locally in chrome.storage.local
  • The password is encrypted before storage using AES-256-GCM with a key derived from the Chrome extension ID
  • Credentials are never transmitted to any server other than the SentimenTrader API

User Preferences

  • Theme, panel position, favorites, and other settings are stored locally in chrome.storage.local
  • These settings never leave your device

Data Transmission

All API requests are made directly from your browser to https://api.sentimentrader.com. No intermediary servers are involved.

What is sent:

  • Your SentimenTrader username and password (HTTP Basic Auth) to authenticate API requests
  • Standard HTTP headers (User-Agent, etc.)

What is received:

  • Sentiment indicator data for your subscribed symbols

Third-Party Services

The extension does not integrate with any third-party analytics, advertising, or tracking services.

Changes to This Policy

Updates to this privacy policy will be reflected in the extension's version history and the Chrome Web Store listing.

Contact

For privacy concerns, please contact the developer through the Chrome Web Store support page.
